# Hybrid CNN-LSTM Sentiment Analysis on Twitter Data


Tweets are classified as Positive, Negative, or Neutral by a CNN-LSTM network trained
on labels generated by TextBlob, a lexicon scorer. The convolution picks up n-gram
patterns and the LSTM reads them in order. The same pipeline is run on two datasets,
a general Kaggle benchmark and tweets collected during the 2024 US election, to see
how it holds up on messy real-world text.

## Pipeline

Identical in both notebooks, so differences in the results come from the data.

1. **Clean.** Lowercase, strip `@handles` and URLs, keep only letters and `#`, remove
   `rt`, collapse whitespace.
2. **Label.** TextBlob polarity: above 0 Positive, below 0 Negative, exactly 0 Neutral.
   The Kaggle `label` column is ignored so both datasets are scored the same way.
3. **Vectorise.** `Tokenizer` with a 10,000 word vocabulary, padded to 100 tokens.
4. **Model.** Embedding(10000 → 100) → Conv1D(128, k=5) → MaxPool(2) → LSTM(128) → Dense(64)
   → Dropout(0.5) → Dense(3, softmax).
5. **Train.** Adam, sparse categorical crossentropy, 10 epochs, batch 32, 80/20 split.

## Findings: Kaggle

600 test tweets.

| | Precision | Recall | F1 | Support |
|---|---|---|---|---|
| Negative | 0.60 | 0.57 | 0.58 | 69 |
| Neutral | 0.71 | 0.82 | 0.76 | 211 |
| Positive | 0.88 | 0.80 | 0.84 | 320 |
| Accuracy | | | 0.78 | 600 |
| Macro avg | 0.73 | 0.73 | 0.73 | 600 |

Negative is the weak class at 0.58 F1. It is also the rarest, at 11% of the test set.
Validation loss bottoms out at 0.56 in epoch 2 and rises to 1.25 by epoch 10, so the
last seven epochs only overfit.

Note: the file has 31,962 tweets; these results come from a random 3,000-tweet sample
of it. The sampling line is not in the notebook, so re-running it as-is trains on all
31,962 and gives different numbers.

## Findings: real-time election tweets

121 test tweets, collected from the Twitter API. The collection script is not in this
repo.

| | Precision | Recall | F1 | Support |
|---|---|---|---|---|
| Negative | 0.89 | 0.70 | 0.78 | 23 |
| Neutral | 0.60 | 0.88 | 0.71 | 24 |
| Positive | 0.91 | 0.84 | 0.87 | 74 |
| Accuracy | | | 0.82 | 121 |
| Macro avg | 0.80 | 0.80 | 0.79 | 121 |

The weak class is now Neutral at 0.60 precision against 0.88 recall: unsure tweets get
dumped there. Validation loss bottoms out at 0.57 in epoch 3.

## Comparison

| | Kaggle | Real-time |
|---|---|---|
| Test size | 600 | 121 |
| Accuracy | 0.78 | 0.82 |
| Macro F1 | 0.73 | 0.79 |
| Worst class | Negative, 0.58 | Neutral, 0.71 |

The election set scores higher despite being far smaller, likely because every tweet is
on one topic and the vocabulary is narrow. With 121 test tweets the gap is within noise.
Positive is the best class and the majority class in both runs. The weak class changed
while the model did not, so the failure mode belongs to the data.

## Running it

```
pip install tensorflow scikit-learn pandas numpy matplotlib seaborn textblob wordcloud
python -m textblob.download_corpora
```

Point `dataset_path` at the CSV and run top to bottom. No TensorFlow seed is set, so
results shift slightly between runs.
